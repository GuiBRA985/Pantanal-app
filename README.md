# Pantanal-App

Projeto Android inicial para o aplicativo Pantanal (Guia e Pousada).

## Estado deste protótipo
- Tela inicial com três caminhos: Avistamentos, Guia e Pousada.
- Avistamentos funciona sem login e salva registros localmente no aparelho.
- Áreas profissionais são placeholders, ainda não conectadas ao Supabase.
- Não inclui envio de fotos/GPS, sincronização ou cadastro Cadastur/CNPJ nesta versão.

## Abrir
1. Descompacte o ZIP.
2. Abra a pasta `Pantanal-App` no Android Studio.
3. Aguarde o Gradle sincronizar.
4. Execute em um aparelho Android ou emulador.
